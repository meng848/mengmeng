会转动的三维世界

给元素打开三维空间，再让 transform 沿 X / Y / Z 轴运动，就能得到纯 CSS 的 3D 动画。本页包含旋转立方体、悬停翻转卡片和一组 3D 小舞台，全部无需 JavaScript。

四、3D 属性速查

属性 / 函数 作用 页面中的用法
perspective 设置观察者的透视距离，值越小立体感越强 立方体场景 700px，卡片 800px，舞台 600px
perspective-origin 透视点位置，默认元素中心 本页使用默认值
transform-style: preserve-3d 让子元素保留三维坐标系，不拍平 立方体、翻转卡片、棱锥的父级
backface-visibility: hidden 元素背面朝向观察者时隐藏 立方体各面、卡片正反面
translateZ() 沿 Z 轴前后移动，把“面”推成立体 六个面各平移 ±65px 形成方块
rotateX() / rotateY() / rotateZ() 绕横轴 / 纵轴 / 垂直轴旋转 立方体自转、卡片倾斜、圆环滚动
rotate3d(x, y, z, angle) 绕任意轴向量旋转 可与页面中的单轴旋转组合使用
transform-origin 变换的参考原点，默认 50% 50% 0 本页使用默认中心点
