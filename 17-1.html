{ JSON } 数据格式展示

JSON（JavaScript Object Notation）是一种轻量级的文本数据交换格式，独立于编程语言，如今几乎所有前后端接口都用它传数据。本页把它的语法、取值类型、序列化与解析、网络加载和校验完整演示一遍。

application/json 纯文本 key 必须双引号 无注释 / 无尾逗号

一、六条语法规则

绿色 = 合法，红色 = 非法

1. 键名必须用双引号

✓ { "name": "孟梦" } ✗ { name: "孟梦" }

键名不能用单引号，也不能不加引号。

2. 字符串只能用双引号

✓ "高级网页设计" ✗ '高级网页设计'

单引号、反引号都是 JS 语法，不是 JSON。

3. 不允许写注释

✓ { "a": 1 } ✗ { "a": 1 /* 注释 */ }

JSON 是纯数据，不能有 // 或 /* */。

4. 最后一个成员不能有逗号

✓ { "a": 1, "b": 2 } ✗ { "a": 1, "b": 2, }

尾逗号在 JS 里没事，在 JSON 里直接报错。

5. 值的类型有限

✓ 只有 6 种(见下节) ✗ undefined / 函数 / NaN

不支持 undefined、function、日期对象、Infinity。

6. 顶层可以是对象或数组

✓ { … } 或 [ … ] ✗ 单独的 "abc"（严格版不允许）

实际接口一般最外层都包一个对象。
