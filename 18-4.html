ECharts 地图路线：route1 与 route2

用 ECharts 的 geo 组件加载本地 SVG 地图（西西里岛史前地形图），把图中两个路线区域注册为可选区域， 点击顶部按钮即可高亮对应路线并弹出说明。

18-4 · echarts 5.5.1

提示：点击上方 route1 / route2 按钮切换路线，滚轮缩放、拖拽平移

route1Elymoi 西部路线

族群
Elymoi（艾利米人），西西里最早的定居族群之一
路径
Erice → Segesta → Entella → M. d'Oro → Palermo
特征
山地与海岸混合地形，Erice、Segesta 保留古希腊时期遗址
长度
约 120 km

route2Sikeloi 东南路线

族群
Sikeloi（西凯尔人），聚居于岛屿中东部
路径
Palermo 南侧 → Colle Madore → Monte Marzo → Ragusa
特征
穿越 Cavaliere 平原与 Etna 火山南麓，串联多处遗址点
长度
约 180 km

本地依赖

cdn/echarts/echarts.min.js 与 cdn/echarts/Sicily_prehellenic_topographic_map.svg 已下载到项目内，页面不引用任何外部地址。

SVG 地图注册

用 fetch 读取 SVG 文本，再执行 echarts.registerMap('sicily', { svg })；SVG 中 name="route1" 的路径会自动成为可选中区域。

按钮实现

两个按钮并非 DOM 元素，而是隐藏在顶部网格中的 scatter 数据点，selectchanged 再把选择同步给 geoSelect 与 showTip。
