SVG 图标 —— Lucide 图标库

Lucide 是一套SVG 矢量图标库。本页的图标不是字体字符，而是一个个真正的 <svg> 图形：线条路径画出来的，能无损缩放、能用 CSS 直接改描边粗细。图标库文件已下载到本地 cdn/lucide/lucide.min.js，页面通过 data-lucide 占位标签把它渲染成 SVG。作者：孟梦。

一、常用图标

HTML 里只写 <i data-lucide="house"></i>，页面底部的 lucide.createIcons() 会把每个占位标签替换成一段 <svg> 代码。把鼠标放到图标上看效果。

二、SVG 的优势：直接改图形本身

Lucide 的 SVG 用 stroke="currentColor" 画线，所以颜色继承文字的 color；线宽由 stroke-width 决定；矢量路径让任何尺寸都清晰锐利。这些属性都能被普通 CSS 覆盖。

尺寸缩放 width / height: 18 → 34 → 62px
描边粗细 stroke-width: 1 → 2 → 3.5
颜色继承 color: ...（SVG 跟随文字颜色）
任意旋转 transform: rotate(...)
随文混排 收到 3 条新消息 离线状态下无法同步

三、两种使用方式

方式一（本页采用）：先在 HTML 写占位标签，再用本地 lucide.min.js 批量替换成 SVG。方式二：把 SVG 代码直接写进 HTML，完全不需要脚本。

<!-- 方式一：运行时渲染（本页写法） -->
<script src="cdn/lucide/lucide.min.js"></script>
<script>lucide.createIcons();</script>
<i data-lucide="heart"></i>
↑ 渲染后变成 ↓
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24"
     viewBox="0 0 24 24" fill="none" stroke="currentColor"
     stroke-width="2" stroke-linecap="round" class="lucide lucide-heart">
  <path d="M19 14c1.49-1.46 3-3.21 3-5.5A5.5..."/>
</svg>

四、字体图标 vs SVG 图标

对比项 字体图标（Font Awesome，见 13-1） SVG 图标（Lucide，本页）
本质 字体文件里的一个字符 画出来的矢量图形
本页依赖 all.min.css + woff2 字体 lucide.min.js（或直接内联 SVG）
缩放 跟随 font-size 任意放大缩小不失真
颜色 color 改字体色 color 继承给 stroke
线宽 整套字体统一，不可单独调 可用 stroke-width 逐个调整
多色图标 需要堆叠技巧 可给不同 path 单独上色
代表库 Font Awesome、iconfont Lucide、Feather、Heroicons
