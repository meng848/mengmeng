二、下导航的结构

4 个导航项：首页 / 消息 / 收藏 / 更多。每项 = 图标 + 文字 + 数字徽章 + 右上角红点。看一眼底部导航，再对照代码：

<nav class="meng_tabbar">
  <a class="meng_tab meng_tab-active">
    <span class="meng_tab-ico">
      <!-- 字体图标：一个空 i + 类名 -->
      <i class="iconfont icon-shouye1"></i>
      <span class="meng_badge">8</span>  <!-- 数字徽章 -->
    </span>
    <span class="meng_tab-text">首页</span>
    <span class="meng_dot"></span>  <!-- 右上角红点 -->
  </a>
  <!-- 消息 36 · 收藏 12 · 更多 3，同结构重复 4 项 -->
</nav>

/* CSS 关键三行：贴底、全屏、等分自适应 */
.meng_tabbar {
  position: fixed; left: 0; right: 0; bottom: 0;
  width: 100%;                 /* 全屏宽度 */
  padding-bottom: env(safe-area-inset-bottom);
}
.meng_tab { flex: 1 1 0; /* 4 项均分，宽度随屏幕自适应 */ }

三、实现要点

  • 全屏宽度：position: fixed + left/right: 0 + width: 100%，任何屏宽都贴满底部。
  • 自适应等分：导航项 flex: 1 1 0，320px 小屏到桌面宽屏永远四等分，不会溢出换行。
  • 数字徽章：position: absolute; top: -6px; right: -12px; 挂在图标右上角，白描边浮在导航条上。
  • 红点：绝对定位在导航项右上角 top: 4px; right: 4px;，带白色描边与呼吸闪烁动画。
  • 安全区：viewport-fit=cover + env(safe-area-inset-bottom)，刘海屏底部不被遮挡；正文用 padding-bottom 让位。
  • 字体图标：图标大小改 font-size，颜色改 color（激活项变主题色），与文字完全一致的操控方式。
