JavaScript 六种基础数据类型

课堂练习 14-2 — 点击按钮查看每种类型的运行结果

① String 字符串

用单引号、双引号或反引号包裹的文本。

let mm_s1 = "孟梦"; let mm_s2 = '高级网页设计'; let mm_s3 = `你好, ${mm_s1}!`;
点击运行查看

② Number 数字

整数、浮点数，还有特殊值 NaN 和 Infinity。

let mm_n1 = 100; let mm_n2 = 3.14; let mm_n3 = 1/0; // Infinity let mm_n4 = "abc" * 2; // NaN
点击运行查看

③ Boolean 布尔

只有两个值：true 或 false。

let mm_b1 = true; let mm_b2 = false; let mm_b3 = 10 > 5; // true let mm_b4 = "" === 0; // false
点击运行查看

④ Undefined 未定义

声明了变量但未赋值时的默认值。

let mm_u; // 未赋值 let mm_u2 = undefined; let mm_o = {}; // mm_o.missing 也是 undefined
点击运行查看

⑤ Null 空值

主动赋值的"空"。注意：typeof null 返回 "object"（历史遗留 bug）。

let mm_n = null; console.log(typeof mm_n); // "object" let mm_user = null; // 用户还没登录
点击运行查看

⑥ Symbol 符号 ES6

ES6 新增，每个 Symbol 都是唯一的，用作对象的私有/唯一属性键。

let mm_sym1 = Symbol("id"); let mm_sym2 = Symbol("id"); // mm_sym1 !== mm_sym2（唯一！）
