会变色的 CSS 变量 —— 孟梦的练习页

CSS 变量（正式名称：CSS 自定义属性）让我们把常用的颜色、间距等值先命名保存，再通过 var() 随处引用。改一处变量，全页联动更新。本页由 孟梦 使用原生 HTML + CSS 完成，无 JavaScript、无 CDN。

一、定义与引用

变量写在 :root 里成为全局变量，用 -- 前缀命名；使用时写 var(--变量名)。下面色块的颜色全部来自本页顶部 :root 中的定义。

var(--meng-primary)

页面主色

var(--meng-primary-dark)

主色加深

var(--meng-accent)

强调色

var(--meng-ink)

正文墨色

二、一段定义，处处生效

这是本页 :root 中的变量定义代码。所有以 -- 开头的行都是自定义属性，本身不产生样式，只为 var() 提供值。

/* 定义：写在 :root 上，全页可用 */
:root {
  --meng-primary: #5b4bdb;
  --meng-accent: #0e9f9a;
  --meng-radius: 14px;
}

/* 使用：任何选择器里都能引用 */
h1 { color: var(--meng-primary); }

三、主题切换：一次改写整组变量

勾选下面的开关，后代选择器 :checked ~ ... 会把容器上的多个变量同时换值 —— 背景、文字、按钮颜色一起更新，这就是"换肤"的原理。

孟梦的主题卡片

这张卡片的背景、文字、按钮颜色都由 --meng-demo-* 三组变量控制。勾选上方复选框，三组变量同时改写，整张卡片瞬间换肤。

var(--meng-demo-btn)

四、作用域：全局与局部

写在 :root 上是全局变量；写在普通选择器上则是局部变量，只在该元素及其子元素内生效。三张卡片各自定义了同名变量 --meng-tag，互不干扰。

局部 A

--meng-tag: #e85d4a

定义在 .meng_scope-a 上，只有这张卡片里的徽章是红色。

局部 B

--meng-tag: #43a982

同名变量在不同选择器里可以取不同值，这正是层叠与作用域的魅力。

局部 C

--meng-tag: #477fce

孟梦的三张卡片，三种颜色，一个变量名。

五、回退值：var() 的保险丝

var(--名称, 备用值) 的第二个参数是回退值：变量不存在时自动使用备用值，避免样式"整段失效"。

  • var(--meng-primary) —— 变量存在，显示主色紫
  • var(--meng-not-exist, #e85d4a) —— 变量不存在，回退为橙红
  • linear-gradient(var(--meng-accent), var(--meng-not-exist, #f2ae3d)) —— 存在与回退混用，渐变从青绿到金黄

六、CSS 变量速查表

语法 含义 本页示例
--名称: 值; 声明自定义属性（变量） --meng-primary: #5b4bdb
var(--名称) 引用变量的值 色块、按钮、徽章的颜色
var(--名称, 回退值) 变量无效时使用回退值 第三组圆点演示
:root { ... } 定义全局变量的最佳位置 本页全部 --meng-* 全局变量
元素 { --x: ...; } 局部变量，仅本元素及子元素可用 主题卡片与三张作用域卡片
calc(var(--x) + 10px) 变量参与计算 本页圆角 --meng-radius 可配合 calc 缩放
@property --名称 注册变量类型，使其可被动画过渡 进阶特性，现代浏览器支持
变量命名规范 必须以 -- 开头，区分大小写 本页统一使用 --meng- 前缀
