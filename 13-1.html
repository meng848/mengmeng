字体图标 —— Font Awesome 图标集

Font Awesome 把上千个图标做成了一套网页字体：每个图标都是字体文件里的一个"字符"。本页不连接外网，全部资源都已下载到本地 —— 样式表 cdn/fontawesome/css/all.min.css 加上 cdn/fontawesome/webfonts/ 下的 woff2 字体文件。图标写法只是一个 <i> 标签加类名，然后就能像文字一样改大小、改颜色。作者：孟梦。

二、字体图标的特性：像文字一样操控

既然是字体，font-size 控制大小、color 控制颜色、可以旋转、可以做动画 —— 全部用普通 CSS 就能实现，不需要切图。

大小 font-size: 18px / 38px / 64px
颜色 color: ...
旋转 fa-rotate-90 / fa-rotate-180
动画 fa-spin 旋转 / fa-beat 心跳
堆叠 fa-stack 两层叠加出徽标
随文混排 收到 6 条新消息 请先保存再退出

三、字体图标的原理

标签本身是空的，图标来自 CSS 的 ::before 伪元素：它把一个十六进制编码"翻译"成字体文件里的字形，浏览器把 woff2 当作字体画出来。

<!-- HTML：一个空的 <i> 占位标签 -->
<i class="fa-solid fa-heart"></i>

/* CSS（all.min.css 内部简化）：伪元素输出字体字符 */
.fa-heart::before {
  content: "\f004";                 /* 图标在字体中的编码 */
  font-family: "Font Awesome 6 Free"; /* 来自 webfonts/*.woff2 */
  font-weight: 900;
}
