姓名：孟梦  |  三级项目选题：优酷 Youku
实验方案：① iconfont 字体图标实现下导航   ② SVG symbol 实现同款下导航
核心技术：iconfont.css / svg + symbol + use / 纯 CSS Flex 自适应宽度

🎯 实验目的 & 任务

  • 掌握前端图像解决方案：字体图标 + SVG 矢量图
  • 使用 iconfont.com 下载字体图标文件并本地引用
  • 完成优酷移动端自适应宽度下导航（4 项：首页 / 发现 / 消息 / 我的）
  • 同一导航分别用 字体图标 和 SVG symbol 两种技术实现
  • 用 CSS 修饰图标大小与颜色（激活态变红）

💻 核心代码片段

① 字体图标方案（HTML）

<link rel="stylesheet" href="font/font_5244875_7pxofbmupmt/iconfont.css"> <nav class="mm_yk-tabbar"> <div class="mm_yk-tab-item mmm_active"> <i class="iconfont icon-shouye1"></i><span>首页</span> </div> </nav>

② SVG symbol 方案（HTML）

<svg style="display:none"> <symbol id="mm_ico_home" viewBox="0 0 24 24"><path d="..."/></symbol> </svg> <div class="mm_yk-tab-item"> <svg fill="currentColor"><use xlink:href="#mm_ico_home"/></svg> <span>首页</span> </div>

③ CSS 核心

.mm_yk-tabbar /* 自适应宽度：Flex 等分 */ display: flex; width: 100%; .mm_yk-tab-item { flex: 1; ... } /* 每项等分 */ .mm_yk-tab-item.mmm_active { color: #FF1E32; } /* 优酷红激活态 */

实验小结：两种方案对比——字体图标体积小、适合单色图标、可直接用 CSS 控制颜色大小；SVG symbol 不依赖字体文件、矢量清晰、可做更复杂多色图标。
