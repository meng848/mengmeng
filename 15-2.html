① 条件语句

条件语句根据条件真假，决定执行哪段代码。点击按钮看看效果。

if / else if / else — 根据分数判断等级
function mm_judgeLevel(score) { if (score >= 90) return "A 优秀"; else if (score >= 80) return "B 良好"; else if (score >= 60) return "C 及格"; else return "D 不及格"; }
点击上方按钮运行 →
switch — 根据星期几做不同的事
let mm_day = new Date().getDay(); // 0=周日,1=周一... switch (mm_day) { case 1: return "周一：开班会"; case 3: return "周三：上机实验"; case 5: return "周五：提交作业"; default: return "今天休息"; }
点击运行 →
三元运算符 condition ? a : b — 简写 if/else
let mm_age = 20; let mm_status = mm_age >= 18 ? "成年人" : "未成年人";

② 循环结构

循环让一段代码重复执行。每种循环有不同的适用场景。

for 循环 — 已知循环次数时使用（打印 1~10）
for (let mm_i = 1; mm_i <= 10; mm_i++) { console.log(mm_i); }
点击运行 →
while — 条件为真就继续（从 30 开始，每次 -3，直到 ≤ 0）
let mm_n = 30; while (mm_n > 0) { mm_n = mm_n - 3; // 或 mm_n -= 3; }
点击运行 →
do...while — 至少执行一次再判断条件
let mm_count = 0; do { mm_count++; console.log("第 " + mm_count + " 次"); } while (mm_count < 5);
点击运行 →
for...of — 遍历数组（ES6 推荐）
let mm_fruits = ["苹果", "香蕉", "橙子", "西瓜"]; for (let mm_fruit of mm_fruits) { console.log(mm_fruit); }
点击运行 →
break 跳出循环 · continue 跳过本次（打印 1~20，跳过 7 和 13，到 15 停止）
for (let mm_i = 1; mm_i <= 20; mm_i++) { if (mm_i === 15) break; // 到 15 跳出 if (mm_i === 7 || mm_i === 13) continue; // 跳过 7 和 13 console.log(mm_i); }
