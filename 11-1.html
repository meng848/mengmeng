CSS · Length Units

CSS 里的长度单位

写样式时，宽度、高度、边距、字号都需要长度值。本页用纯 CSS 对照演示绝对单位、相对单位与视口单位，直观感受它们之间的差别。

一、绝对单位

屏幕开发中基本只用 px；其他绝对单位来自印刷领域。换算关系：1in = 96px = 2.54cm = 72pt = 6pc。

二、em 与 rem

em 相对父元素的字号：父级字号被逐层放大后，同为 width: 8em 的盒子一层比一层宽。rem 只相对根元素 (html) 的字号（默认 16px），无论嵌套多深、父级字号怎么变，大小始终一致。

三、百分比 %

% 相对父容器的对应尺寸，是流式布局的基础。下面四条色带相对外层灰色容器的宽度。

width: 25%
width: 50%
width: 75%
width: 100%

四、视口单位 vw / vh / vmin / vmax

以浏览器可视区域为参照：vw = 视口宽度的 1%，vh = 视口高度的 1%，vmin 取宽高中较小者，vmax 取较大者。拖动浏览器窗口大小，下面的方块会跟着变化。

width: 40vw
height: 8vh
18vmin

五、字体相关 ex 与 ch

以当前字体的字形尺寸为参照：ex ≈ 字母 x 的高度，ch ≈ 数字 “0” 的宽度。黄色下划线为 4ex 宽，蓝色下划线为 4ch 宽。

width: 4ex（x 高度 × 4） Hxox
width: 4ch（字符 0 宽度 × 4） H0000
